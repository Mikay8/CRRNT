Project: Marktr
Build a mobile app called Marktr — a finance meets pop culture app for young adults that connects trending news and current events to real stock market data and investing concepts.
Platform & Framework

Expo React Native (mobile first, iOS + Android)
JavaScript/TypeScript
React Navigation for screen routing
React Native Paper for UI styling

Backend

Python with FastAPI
Hosted on the same Replit project as a separate service
REST API consumed by the frontend

Database

Use Replit DB (built-in key-value store) for all server-side storage
Store the daily news batch under a key like news:YYYY-MM-DD
Store cached stock data under keys like stock:AAPL:YYYY-MM-DD

Data & Caching Strategy

News: A scheduled cron job runs once every morning at 8AM and pulls 100 stories from The Guardian API. Stories are stored in Replit DB and served to all users from cache all day. The Guardian API is only hit once per day total.
Stock data: yfinance fetches historical data per ticker on demand. Results cached in Replit DB with a 24-hour expiry. Always check cache before calling yfinance.
No user accounts — saved stories stored locally on device using AsyncStorage only

News Source

Use The Guardian API exclusively — it is completely free, has no request limits, requires no credit card, and covers all four of Marktr's content categories well
Pull 100 stories per day across these search queries:

Celebrity & Pop Culture: q=celebrity OR entertainment OR music OR film
Tech & Startups: q=technology OR startup OR silicon valley OR AI
Government & Politics: q=government OR policy OR federal reserve OR regulation
Sports & Entertainment: q=sports OR NFL OR NBA OR athletics


Pull 25 stories per category so the feed is evenly balanced
At ingest time use Claude (Anthropic API) to tag each story with its category and extract the most relevant stock ticker(s) mentioned or implied in the headline

News Categories
Each story must be tagged with one of:

🎤 Celebrity & Pop Culture
💻 Tech & Startups
🏛️ Government & Politics
🏆 Sports & Entertainment

Core Screens

Home Feed — scrollable card feed of today's 100 news stories. Sticky filter tabs at the top (All / Celebrity / Tech / Government / Sports) styled like Twitter/X. Each card shows headline, category tag, associated stock ticker, and a one-line financial insight generated by Claude at ingest time
Story Detail — tap a card to expand. Shows a price history chart of the related stock, a plain-language explanation of the financial angle written by Claude at ingest time, and a "What If I Invested?" simulator
What If Simulator — user inputs a dollar amount and a past date, app calculates and displays what that investment would be worth today using cached yfinance historical data
Saved — bookmarked stories saved to and read from AsyncStorage on device only

Key Technical Details

Cron job runs at 8AM daily, pulls 100 stories from The Guardian API, runs each through Claude to tag category, extract ticker, write one-line insight and financial explanation, then stores everything in Replit DB
All yfinance calls check Replit DB cache first — only fetch fresh data if missing or older than 24 hours
No authentication, no user accounts, no backend user data of any kind
Charts built with react-native-chart-kit
Dark mode friendly, card-based layout, clean minimal design
Filter tabs sticky at top of feed, do not scroll away
The Guardian API key goes in environment variables

Build Order

Scaffold full folder structure and install all dependencies
Build scheduler.py — cron job that pulls 100 stories from The Guardian API, enriches each with Claude, stores in Replit DB
Build enrichment.py — Claude call that takes a headline and returns category tag, stock ticker, one-line insight, and financial explanation
Build /news endpoint — returns today's cached stories from Replit DB, supports ?category= filter param
Build /stock/:ticker endpoint — returns cached historical data from yfinance, checks cache first
Build frontend screens in order: HomeScreen → StoryDetailScreen → SimulatorScreen → SavedScreen
